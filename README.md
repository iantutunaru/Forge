**Forge** is a Unity practice project where I experiment with existing gameplay techniques while exploring new systems, tools, and workflows.

This project serves as a personal development space for improving my Unity skills, testing mechanics, and building reusable foundations for future game projects.

## Purpose

The main goals of this project are to:
- Practice Unity development techniques
- Experiment with gameplay mechanics
- Learn and test new Unity features
- Improve C# scripting skills
- Build reusable systems for future projects
- Explore better workflows for game development

## Tech Stack

- Unity
- C#
- GitHub

## Project Status

This project is currently in active development and will grow over time as I practice, experiment, and add new systems.
